# Journal de tir

Appli de journal de tir installable, qui marche hors ligne (PWA).

Ouvrir https://timlegrand90-create.github.io/journal-tir/ dans Chrome sur Android, puis menu > Installer l application.

Les donnees restent dans le telephone de chaque utilisateur. Pense a faire des sauvegardes (bouton Sauvegarder).
